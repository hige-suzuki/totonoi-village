# ととのい村

ようこそ、ととのい村へ。

**「ととのい村」は、サウナをきっかけに人が集まり、交流が生まれ、小さな村が少しずつ発展していく様子を描くオリジナルIPプロジェクトです。**

舞台は、地図には載っていない山あいの小さな村。

主人公・ケロンと一緒に村を訪れ、個性豊かな村民たちとの出会い、こもれびサウナの誕生、そして村の成長を見守る物語を描いていきます。

---

## Project Vision

- サウナを通じて、人と人とのつながりを描く
- 読んだ人が少しだけ心を休められる物語を届ける
- 長く愛されるオリジナルキャラクターIPを育てる
- SNS・絵本・グッズ・イベントへ展開できる世界をつくる
