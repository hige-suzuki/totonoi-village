# フライトさん

## Phase 1 基本形

**ステータス:** Version 1.0（正式版）

### 正式基準画像

- 基本形・六方向図：`../assets/characters/flight/phase1/reference/flight_san_phase1_basic_v1.0.png`
- 標準12表情：`../assets/characters/flight/phase1/reference/flight_san_phase1_expressions_v1.0.png`

- 正式基準画像を、フライトさんの素体、頭身、顔、配色、方向別造形および標準表情の基準とする。
- 仕様記述と画像が矛盾する場合は、正式基準画像を優先する。
- Phase 2以降では衣装と小物だけを追加し、Phase 1の素体を変更しない。

### 基本造形

- 動物モチーフはムササビとする。
- 2頭身未満の、頭部が大きく胴体が短いコンパクトな体形とする。
- 頭部は上部を滑らかな曲線でつなぎ、顔の下側へ向けてわずかに絞る。
- 頭髪、モヒカン、毛束および頭頂の突起は設けない。
- 耳は左右に離した小さな半円形とし、先端を尖らせない。
- 腕は胴体側面へ自然に下ろし、腕と胴体の間に折り畳んだ飛膜を見せる。
- 尾は胴体に対して大きい幅広の葉形とし、下背部から一本だけ自然につなげる。
- 尾の大きさ、付け根および先端色を、方向ごとに変更しない。

### 顔・配色

- 本体は落ち着いたグレージュ系とする。
- 顔の左右外側、マズル、腹部および飛膜はクリーム色とする。
- 両目の周囲には、左右がつながらない縦長のトープ色アイパッチを置く。
- 目は濃茶色の縦長楕円とし、小さな白いハイライトを各1点入れる。
- 鼻はくすんだピンクの小さな三角形、標準の口は小さな「人」形とする。
- 耳の内側と足先は、鼻に調和するくすんだピンク系とする。
- 尾の先端には本体より濃いトープ色の切り替えを設ける。
- 線は濃い茶色の太い輪郭線とし、写実的な毛並みや強い陰影を使用しない。

### 腕先・足先

- 独立した手、指、親指、手のひら、手首、爪、足指および関節線を描かない。
- 腕先と足先は、凹凸のない滑らかな単一形状で閉じる。
- 物を持つ表現は、Phase 2以降も腕先と物体の重なりだけで表す。

### Phase 1 標準表情

- `../CHARACTER_RULE.md` が定める共通の12表情を、正式表情セットとして使用する。
- Thinking（考え中）は片目表現にせず、両目を開いた状態で視線の方向と口元によって表現する。
- 表情ごとに頭部輪郭、耳、顔の配色境界、アイパッチおよび目鼻の基本位置を変更しない。

Phase 2は衣装、小物および動作のみを追加し、Phase 1の素体、頭身、顔、配色、飛膜、尻尾および手足の基本造形を変更しない。

### フライングロウリュ

- フライトさん固有の熱波演目とする。
- サウナ室内を飛膜で滑空し、上空にたまった熱気と蒸気を全身の移動によって循環させる。
- 飛膜を開いて揚力と空気の流れを作り、大きな尻尾で飛行姿勢と旋回方向を制御する。
- 飛膜で直接あおぐ表現や、尻尾をタオルまたは道具として扱う表現は行わない。
- 技術の正確さよりも、熱気、躍動感、観客を巻き込むショーとしての楽しさを優先する。

### 標準ポーズ

1. 熱波師Verで飛膜を大きく広げ、サウナ室上空を滑空して熱気を循環させる。
2. 熱波師Verで低いサウナベンチから前方へ飛び出し、飛膜を開き始める。
3. 熱波師Verで空中旋回し、尾で方向を制御する。
4. 熱波師Verで飛行を終え、飛膜を畳みながら着地する。
5. 熱波師Verで片腕を高く掲げ、観客へ呼びかける。
6. 熱波師Verで両腕を広げ、ショーのフィニッシュを決める。
7. 普段着Verでヘッドホンを耳へ装着し、音楽を聴く。
8. サウナVerでサウナベンチへ座る。
9. サウナハットを外し、首掛けタオル姿で、ととのい椅子へ座って休憩する。

### 動作共通ルール

- 飛行時だけ飛膜を全面的に展開し、地上、サウナおよび休憩時は折り畳む。
- 独立した手、指、親指、手のひら、手首、爪、足指および関節線を描かない。
- 物との接触や呼びかけは、滑らかな腕先の位置と重なりだけで表す。
- 尾は全ポーズで一本のみとし、大きさ、付け根および先端色を維持する。

### 公式ポスター

- フライングロウリュ中の飛行姿を画面全面へ配置した縦長ポスターとする。
- 表示文字は大文字の `FLIGHT` だけとする。
- 文字の綴り、キャラクターの衣装、飛膜および尻尾を正式基準画像から変更しない。
- ロゴ、追加コピー、他キャラクターおよび既存作品を想起させる固有意匠を追加しない。
