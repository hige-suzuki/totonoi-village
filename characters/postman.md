# 郵便屋さん

## Phase 1 基本形

**ステータス:** Version 1.0（正式版）

### 正式基準画像

- 正面素体：`../assets/characters/postman/phase1/reference/postman_phase1_front_v1.0.png`
- 基本形・六方向図：`../assets/characters/postman/phase1/reference/postman_phase1_basic_v1.0.png`

- 正式基準画像を、郵便屋さんの素体、頭身、顔、配色、くちばし、喉袋、羽根、脚および方向別造形の基準とする。
- 仕様記述と画像が矛盾する場合は、正式基準画像を優先する。
- Phase 2以降では衣装と仕事道具だけを追加し、Phase 1の素体を変更しない。

### 基本造形

- ととのい村の共通画風を維持しつつ、村の住人よりわずかに高い約2.3〜2.5頭身とする。
- 頭部は丸みのある形状とし、胴体との間にごく短い首を設ける。
- 胴体は腹部に柔らかな丸みを持たせた、やや細身の卵形とする。
- 村に定住せず配達を終えると次の場所へ向かう、明るく軽快な印象を持たせる。
- 頭頂部には、後方へ流れる2先端の小さな羽毛を1組だけ設ける。
- 外周は滑らかにし、写実的な羽毛、細かな毛束および表面テクスチャを使用しない。

### 顔・くちばし・喉袋

- 目は小さな濃茶色の縦長楕円とし、白いハイライトを各1点入れる。
- 眉、まつ毛、眼鏡および目の周囲の色柄を設けない。
- 上くちばしは落ち着いた橙色とし、正面では左右へ広がりながら中央へ緩やかに絞られる形状とする。
- 上くちばしを器状、平板状または過度に巨大な形状にしない。
- 喉袋は上くちばしの下に独立した淡い杏色の面として設け、上胸までに収まる浅い丸形とする。
- 側面では上くちばしを前方へ自然に突出させ、喉袋との境界を明確にする。

### 羽根・脚・足

- 腕ではなく、左右一対の折り畳んだ羽根として造形する。
- 各羽根の先端は、幅のある3枚の風切羽として表現する。
- 郵便屋さんには、共通の「腕先を分割しない」ルールを適用しない。
- Phase 2以降では羽根を開く、上げる、物へ重ねるなど、鳥の羽根として動かしてよい。
- 脚は橙色の短中丈とし、胴体の下から明確に見せる。
- 足は橙色の水かき足とし、前方へ向かう3つの丸い区切りを持つ簡潔な形状とする。
- 写実的な関節、爪および細かな羽毛線を描かない。

### 配色・線画

- 顔、首、胸および腹部は温かいアイボリーとする。
- 頭頂部、背面および羽根は、くすんだ淡い青灰色とする。
- 羽根先は一段濃いスレートブルーとする。
- 上くちばしと脚は落ち着いた橙色、喉袋は淡い杏色とする。
- 輪郭線は濃い茶色の均一で滑らかな太線とする。
- 強い陰影、光沢、写実的な質感および立体レンダリングを使用しない。

### Phase 1 表情運用

- 郵便屋さんのPhase 1では、標準12表情および固有表情集を制作しない。
- 正面素体の明るく気さくな標準表情を、Phase 1の表情基準とする。
- 必要な表情は登場場面ごとに展開するが、目、くちばし、喉袋および頭部輪郭の基本位置を変更しない。

## Phase 2 仕事着・ポーズ

**ステータス:** Version 1.0（正式版）

### 正式基準画像

- 仕事着Ver・四方向図：`../assets/characters/postman/phase2/work/reference/postman_phase2_work_v1.0.png`
- 標準ポーズ集：`../assets/characters/postman/phase2/poses/reference/postman_phase2_poses_v1.0.png`

- Phase 2は衣装、仕事道具および動作のみを追加し、Phase 1の素体、頭身、顔、配色、くちばし、喉袋、羽根および脚を変更しない。
- 仕様記述と画像が矛盾する場合は、正式基準画像を優先する。

### 郵便ジャケット

- くすんだ濃い青緑色の、上腹部までの短丈ジャケットとする。
- 前面中央に細い金色のファスナーを設ける。
- 左右の胸に、小さなフラップ付きポケットを1個ずつ設ける。
- 裾に細いマスタード色のパイピングを設ける。
- 左右の羽根を外へ出す大きな開口部を設け、羽根を袖へ変形させない。
- 文字、ロゴ、郵便記号、階級章および装飾的な紋章を付けない。

### 制帽

- ジャケットと同じ濃い青緑色の、丸みのある郵便制帽とする。
- 短いつばと、細いマスタード色の帯を設ける。
- 頭頂部の2先端の羽毛は、帽子の後方上部から自然に見せる。
- 警察帽、軍帽、車掌帽およびパイロット帽へ寄せない。

### メッセンジャーバッグ

- 温かいコニャックブラウンの、厚みのある角丸長方形とする。
- 大きなフラップと金色の留め具を1個設ける。
- バッグ本体は、本人の左腰へ常に固定する。
- ストラップは本人の右肩から胸を斜めに通り、左腰のバッグへ接続する。
- 方向やポーズによってバッグを右腰へ移動させず、ストラップの掛け方を反転させない。
- 文字、ロゴ、郵便記号、宛名および装飾柄を入れない。

### 足元

- 靴、ブーツおよび脚衣を使用しない。
- Phase 1と同じ橙色の脚と水かき足を見せる。

### 標準ポーズ

1. **飛行**：両羽根を大きく広げ、胴体を進行方向へ傾けて飛ぶ。脚は後方へ自然に流し、制帽とバッグを身体へ固定する。
2. **小包の受け渡し**：地面へ立ち、上体をわずかに前へ傾け、両羽根の先端を小包の左右下部へ重ねて相手へ差し出す。

### 羽根・小物の保持ルール

- 郵便屋さんは、羽根を開く、上げる、曲げる動作を行ってよい。
- 物を保持する際は、羽根先と物体の重なりで表現する。
- 人間の手、指、親指、手のひらおよび手首を追加しない。
- 小包は無地のクラフト紙で包んだ角丸長方形とし、濃茶色の紐を十字に掛ける。
- 小包に宛名、切手、ロゴ、商品名および読めない文字を入れない。
- 小包をくちばしまたは喉袋で運ばない。
- 飛行時もバッグを左腰へ固定し、ストラップとバッグを浮かせたり複製したりしない。

## キャラクターの核
ととのい村と外の世界を行き来し、手紙や荷物だけでなく、新しい情報や文化も運んでくる郵便屋。

村の外を知る存在だが、自分から村を変えようとはしない。

いつもの配達の中で何気なく届けたものや言葉が、結果として村の新しい出来事につながることがある。

## キャッチコピー
ととのい村と外の世界を結ぶポストマン

## 郵便屋としての役割
- ととのい村と外の世界をつなぐ。
- 手紙や荷物を届ける。
- 雑誌やパンフレットなど、外の世界の情報も運ぶ。
- 村人が知らない文化を知っている。
- 外の文化を大げさに紹介するのではなく、日常会話の中で自然に伝える。
- 配達そのものが仕事であり、村を導くことを目的にはしていない。
- 村へ新しい出来事が生まれるきっかけになることがある。

## 性格
- 明るい
- 気さく
- 情報通
- 村のみんなと顔なじみ
- 必要以上に長居はしない
- 自分が重要なことを運んでいるという意識はあまりない

## 村との距離
- ととのい村の住人ではない。
- 定期的に村へ配達に来る。
- 村人とは親しいが、配達が終わると次の場所へ向かう。
- 外から来る客ではなく、村の日常に組み込まれた存在。
- 村人にとって、外の世界を感じられる身近な相手。

## 話し方
- 明るく気軽に話す。
- 外で見聞きしたことを、特別な話のようには語らない。
- 「外ではそう呼ぶよ」など、何気ない一言で新しい情報を伝える。
- 説明役になりすぎない。
